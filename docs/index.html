چرا این کتاب؟

React را نمی‌توان با حفظ‌کردن API یاد گرفت. این کتاب به‌جای فهرست‌کردن هوک‌ها، مدل ذهنی می‌سازد و هر مفهوم را با کد واقعی، اشتباه رایج و سؤال مصاحبه‌اش تثبیت می‌کند.

Actions، useActionState، useOptimistic، use()، useEffectEvent، <Activity> و React Compiler 1.0 — با تفکیک دقیق «پایدار» از «آزمایشی».

معماری و Clean Code

Production Ready

تست با Vitest/Playwright، امنیت و CSP، دسترسی‌پذیری و RTL، Web Vitals، Docker و CI، مهاجرت ۱۸ → ۱۹ و انتخاب فریم‌ورک.

پیش‌نمایش صفحات

نمونه‌هایی از صفحه‌آرایی کتاب — فهرست، جدول مرجع هوک‌ها، کد Actions، کارگاه و پرسش‌های مصاحبه.

فهرست مطالب نقشه کامل هوک‌های React 19.2 فرم‌ها و Actions کارگاه مینی‌پروژه‌ها پرسش‌های مصاحبه

کدی که در کتاب می‌خوانید

هر مثال، کد واقعی و قابل‌اجرا با TypeScript است؛ نه شبه‌کد. الگوی React 19 برای فرم‌ها در چند خط:

  • useActionState — state، pending و خطا در یک هوک
  • useOptimistic — پاسخ آنی با بازگشت خودکار
  • Suspense — بارگذاری اعلانی بدون isLoading
  • useFormStatus — دکمه‌ای که خودش می‌داند در حال ارسال است
  src/features/checkout/CheckoutForm.tsx
import { useActionState, useOptimistic }
  from 'react';

export function CheckoutForm({ cart }: Props) {
  const [state, submit] =
    useActionState(placeOrder, null);
  const [items] = useOptimistic(cart.items);

  return (
    <form action={submit}>
      <Suspense fallback={<Skeleton />}>
        <CartSummary items={items} />
      </Suspense>
      {state?.error && <Alert msg={state.error} />}
      <SubmitButton />  // useFormStatus()
    </form>
  );
}
