Why this guide

Actions-first، با مدل ذهنی درست

هر مفهوم اول روی مدل اجرای React می‌نشیند؛ بعد در یک نمونهٔ واقعی پیاده می‌شود.

مدل ذهنی رندر، درست
می‌دانی state کِی عکس می‌گیرد، رندر چند مرحله دارد و چرا کامپوننتت دوباره اجرا شد.
Actions در React 19
useActionState، useFormStatus و useOptimistic؛ فرم‌ها بدون state دستی و بدون onSubmit.
داده با Suspense و use
واکشی بدون آبشار، مرزهای Suspense و خواندن Promise با API use در رندر.
React Compiler و Concurrent
خداحافظی با memoization دستی؛ useTransition، useDeferredValue و <Activity>.
معماری در مقیاس
ساختار feature-based، الگوهای Compound و Headless، state در مقیاس با Zustand و Redux.
کارگاه و مصاحبه
هشت مینی‌پروژه، چهل‌وپنج پرسش مصاحبه و صد‌وسی‌وسه مدخل واژه‌نامه.
